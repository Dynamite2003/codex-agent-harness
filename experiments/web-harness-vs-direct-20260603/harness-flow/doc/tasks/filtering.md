# 筛选模块

## 模块目标

实现 `filterTasks` 和负责人筛选选项生成规则，让搜索、状态筛选和负责人筛选影响看板可见任务，同时不改变完整任务列表。

## 依赖输入

- `doc/proposal.md`
- `doc/detailed-design.md`
- 数据模型模块输出
- `src/app.js`

## 不做什么

- 不计算 KPI。
- 不读写 `localStorage`。
- 不删除或修改任务数据。

## 任务 checklist

- [x] 实现 `filterTasks(tasks, filters)` named function，并确保可在非浏览器环境调用。
- [x] 支持 `query` 关键词搜索，大小写不敏感。
- [x] 让关键词至少匹配标题、负责人和备注。
- [x] 支持状态筛选；`All` 返回所有状态，其他值只返回对应状态。
- [x] 支持负责人筛选；`All` 返回所有负责人，其他值只返回对应负责人。
- [x] 将搜索、状态和负责人筛选条件组合为交集。
- [x] 实现负责人选项生成逻辑，来源为当前完整任务列表。
- [x] 确保负责人选项第一个值固定为 `All`，其余值去重。
- [x] 在新增、删除、导入任务后触发负责人选项重新生成。
- [x] 当前筛选 owner 已不存在时，将 owner 筛选回退为 `All`。

## 验收标准

- 搜索和筛选只影响可见任务，不改变 `appState.tasks`。
- 筛选无结果时四个看板列仍然存在。
- 负责人筛选选项不会从当前搜索结果派生，而是从完整任务列表派生。
- 删除某负责人最后一个任务后，失效 owner 筛选会回退到 `All`。

## 测试要求

- [x] 验证关键词匹配标题、负责人和备注。
- [x] 验证状态筛选、负责人筛选和组合筛选。
- [x] 验证大小写不敏感搜索。
- [x] 验证 owner 选项去重和 `All` 首项规则。

## 验证记录

- `tests/test_app_logic.py` 覆盖关键词、大小写不敏感、状态、负责人和组合筛选。
- DOM smoke 通过搜索、状态筛选、负责人筛选和筛选无结果 empty state 验证。
- 负责人选项由完整任务列表生成，并在导入/删除后重渲染；失效 owner 由 `ensureValidFilters` 回退到 `All`。

## 风险和注意事项

- `filterTasks` 应保持纯函数，不要在其中修改 filters。
- owner 失效回退可以由渲染或交互模块处理，但必须在重渲染前生效。
