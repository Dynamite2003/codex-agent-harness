# Direct Baseline

This directory is a direct-style baseline for the same task:

> 给一个无依赖 Todo Web App 增加“截止时间 + 逾期标记”能力。

It intentionally contains only the implementation artifact and this short note. It does not include Spec, design, task, or verification documents.
