# Vibe2Spec Demo Project

这是一个课程展示用的完整轻量样例，演示从一句需求到最终实现的 Vibe2Spec 流程。

原始需求见 [task.md](task.md)。

产物链路：

1. [doc/proposal.md](doc/proposal.md)：Spec-first 需求，包含 EARS、ADR Candidates、GIVEN-WHEN-THEN。
2. [doc/detailed-design.md](doc/detailed-design.md)：详细设计，收敛 ADR，说明模块、契约和测试策略。
3. [doc/tasks/progress.md](doc/tasks/progress.md)：任务进度和执行顺序。
4. [doc/tasks/deadline-todo.md](doc/tasks/deadline-todo.md)：可执行任务切片。
5. [index.html](index.html)：最终无依赖静态实现。
6. [doc/verification.md](doc/verification.md)：验证记录。

打开方式：

```bash
open examples/demo-project/index.html
```

也可以用浏览器直接打开 `index.html`。
